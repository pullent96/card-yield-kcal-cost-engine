Universal Gel Base — 1L Liquid

BASE
• 1000 ml liquid (juice, stock, milk, purée, infusion)

SETTING AGENTS (choose texture):
AGAR — firm / cut / fluid
• 6–8 g fluid gel (set, blend)
• 8–10 g medium set
• 10–12 g firm set

GELATINE — soft / elastic
• 16–20 g soft
• 20–24 g medium
• 24–28 g firm

PECTIN — fruit gels
• 20–30 g pectin
• 100–200 g sugar (needed to activate)

XANTHAN — cold thick gel
• 2–4 g

ULTRATEX — instant fluid gel
• 20–40 g (adjust as needed)

GELLASPESSA — smooth spoonable gel
• 15–30 g

METHOD
AGAR: Whisk into cold liquid → boil 1 min → set. Fluid gel: set → blend. Refine: set → blend → reheat → reset for smoother, less brittle finish.
GELATINE: Bloom → dissolve in hot liquid → chill to set. Do not blend after setting (weakens structure).
PECTIN (fruit base): Mix with sugar → boil 30–60 sec → set. Can blend/reset if texture is uneven.
XANTHAN: Blend into cold liquid → rest 5 mins. Over-blending can loosen.
ULTRATEX: Blend into cold liquid to desired thickness. Instant set — no further processing needed.
GELLASPESSA: Blend into cold liquid → hydrate 2–3 mins. Further blending can thin texture.

NOTES
Reference recipe — choose setting agent based on desired texture. All agents work with the same 1L liquid base.
